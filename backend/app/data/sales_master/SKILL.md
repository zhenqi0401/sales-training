## 模块一：学习模块

当用户说"学习"、"教我"、"看看产品知识"、"话术"等时触发。

### 学习路径

```
新人入门 → 产品知识 → 销售话术 → 陌拜SOP → 心态建设 → 综合实战
```

**新人入门路径（推荐顺序）：**

1. **心态建设**（模块一）→ 2. **产品知识**（模块二）→ 3. **ROI算账**（模块三）→ 4. **陌拜SOP**（模块四）→ 5. **异议处理**（模块五）→ 6. **综合实战**

### 各模块核心内容

**心态建设**（详见 `references/knowledge_base.md` 模块一）
- 80%客户说No是业务常态
- 六个基本功：把拒绝和失败分开 / 别把拒绝当成对你的拒绝 / 能量补给系统 / 合理期望值 / 课题分离 / 把拜访当成练习
- 受挫调整七步法：允许难过15-30分钟 → 问三个问题 → 写下来 → 找改进点 → 重新启动 → 建立挫折日志 → 记住成功案例

**产品知识**（详见 `references/knowledge_base.md` 模块二）
- 卖点：光（环境光收集）+ 控（延缓眼轴）+ 据（临床数据）+ 龄（6-18岁）
- 竞品对比：星趣控36% → 我们76%；朗星眸39% → 杭州儿童医院认证；蔡司/依视路 → 毛利更足
- 三个核心数字：76%、478元、3202元

**ROI算账**（详见 `references/knowledge_base.md` 模块三）
- 月配30副案例：全部换高境光利润提升73%
- 6副按建议价推：月多赚13,212元
- 话术核心：让老板自己算出"月多赚近5-1万"

**陌拜SOP**（详见 `references/knowledge_base.md` 模块四）
- 六大展业工具：名片 / 样品 / 彩页 / 退轴案例 / 合同 / 短视频
- 进门三步走：破冰（用数据证明价值）→ 身份反转（"我不是来卖镜片的"）→ 异议处理+低门槛试探
- 离场三结果：当场签约 / 约下次时间 / 加微信发方案

**异议处理**（详见 `references/knowledge_base.md` 模块五）
- "太贵了"→ 拆分法：每天6块钱 + 利润1.5倍 + 店员更愿意推
- "怕度数控制不住"→ 临床背书+1年保险，零风险
- "没听过品牌"→ 坦诚承认 + 2副测试 + 医院案例
- "先考虑考虑"→ 稀缺法：占名额，本月首单支持

## 模块二：考核模块

当用户说"考核"、"考试"、"做题"、"测验"等时触发。

### 考核方式

**1. 随机出题（10题，80分及格）**
- 从题库随机抽取，覆盖7个模块
- 选择题 + 判断题 + 情景题
- 立即出答案，逐题打分

**2. 模块专项考核**
- 可指定模块：如"考我陌拜SOP"、"考我产品知识"
- 10题/模块，及格线80分

**3. 综合考核（20题）**
- 全部模块混合，模拟真实考试
- 通过线80分

**4. 情景模拟**
- AI扮演难搞客户，随机出场景
- 用户回答后AI评分+反馈
- 场景包括：太贵了 / 没听过品牌 / 考虑考虑 / 怕度数控制不住 / 进店开场

### 考核流程

```
开始考核 → 随机/指定模块 → 显示题目 → 用户回答 →
逐题判定对错 → 给出正确答案 → 记录错题 →
汇总分数 → 通过/不及格 → 生成薄弱点报告
```

### 评分标准

| 分数 | 评价 |
|------|------|
| 90-100 | 🌟 销冠预备役 |
| 80-89 | ✅ 合格，可以上阵 |
| 60-79 | ⚠️ 还需加强，继续学习 |
| <60 | ❌ 不及格，建议重学模块一（心态建设） |

## 模块三：薄弱点追踪

当用户说"我的错题"、"薄弱点"、"复习"、"看报告"等时触发。

### 记录格式

每次考核自动记录：
```
日期 | 模块 | 错题号 | 错因 | 下次复习时间
```

### 薄弱点分析

根据错题分布，自动识别薄弱模块，优先复习高频错题。

**薄弱点等级：**
- 🔴 严重（错题率>40%）：优先复习
- 🟡 一般（错题率20-40%）：加强练习
- 🟢 良好（错题率<20%）：保持即可

### 个性化复习计划

根据薄弱点，推荐学习顺序：
```
薄弱模块 → 相关话术 → 情景练习 → 再次考核
```
