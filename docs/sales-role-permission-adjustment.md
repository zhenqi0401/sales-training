# 销售角色与权限调整需求说明

日期：2026-06-11

## 1. 调整目标

在现有销售培训系统内完成销售部新增需求承载，不新增平台、不拆分系统数量。

本次调整目标：

- 管理端仅保留一种角色：管理员，拥有全部后台权限。
- 培训端保留两种角色：销售、学员。
- 销售角色在培训端具备销售看板、销售方法论、个人销售语音文件上传等增强能力。
- 学员角色保持现有通用学习权限不变。
- 销售和学员共享课程学习、话术学习、考试、Agent 话术演练等培训能力。

## 2. 角色定义

| 端 | 角色 | 建议 role 值 | 定位 |
| --- | --- | --- | --- |
| 管理端 | 管理员 | `admin` | 后台唯一管理角色，拥有全部管理权限 |
| 培训端 | 销售 | `sales` | 销售人员，拥有培训端通用能力和销售增强能力 |
| 培训端 | 学员 | `student` | 普通学习用户，保持现有培训端通用权限 |

## 3. 权限范围

### 3.1 管理员

管理员只使用管理端，拥有全部后台权限：

- 用户管理
- 门店管理
- 产品分类管理
- 产品知识管理
- 视频、PPT、课程管理
- 话术管理
- 题库、AI 出题
- 试卷、考试管理
- 总体数据看板
- 销售语音文件后台查看
- 销售方法论后台查看和管理

管理员不需要查看 Agent 话术演练记录。Agent 话术演练本阶段只作为培训端前端入口和展示能力，后续再完善记录、评分、复盘等闭环。

### 3.2 销售

销售只使用培训端。

销售拥有培训端公共能力：

- 课程学习
- 话术学习
- 考试
- 和 Agent 进行话术演练
- 收藏、学习记录、个人中心等现有通用能力

销售拥有销售增强能力：

- 查看销售看板
- 查看销售方法论
- 上传个人销售语音文件
- 通过个人销售语音文件输入沉淀销售方法论

销售看板和销售方法论对所有销售角色可见，不按个人隔离。

个人销售语音文件由销售本人上传，管理员可在后台查看全部销售上传的语音文件。

### 3.3 学员

学员只使用培训端，保持现有通用权限不变：

- 课程学习
- 话术学习
- 考试
- 和 Agent 进行话术演练
- 收藏、学习记录、个人中心等现有通用能力

学员不可访问：

- 销售看板
- 销售方法论
- 个人销售语音文件上传
- 销售语音文件后台查看

## 6. 后端权限调整任务

### 6.1 角色枚举统一

统一系统角色为：

- `admin`
- `sales`
- `student`

需要清理当前系统中已有的角色命名差异：

- 后端旧角色：`super_admin`、`training_admin`、`instructor`、`student`
- 管理端旧类型：`admin`、`trainer`、`student`

建议迁移规则：

- `super_admin` -> `admin`
- `training_admin` -> `admin`
- `instructor` -> 按业务确认后迁移为 `admin` 或 `student`
- `student` -> `student`
- 需要销售权限的用户单独批量设置为 `sales`

### 6.2 权限依赖

在后端补充常用权限依赖：

- `require_admin`
- `require_training_user`：允许 `sales`、`student`
- `require_sales`
- `require_sales_or_admin`

### 6.3 管理接口权限

以下接口统一限制为 `admin`：

- `/users`
- `/stores`
- `/categories`
- `/videos`
- `/products` 管理写接口
- `/scripts` 管理写接口
- `/questions`
- `/exam-papers`
- `/dashboard/admin-overview`
- 销售语音文件后台查看接口
- 销售方法论后台管理接口

### 6.4 培训端公共接口权限

以下接口允许 `sales`、`student`：

- 课程学习接口
- 话术学习接口
- 考试答题接口
- 学习进度接口
- 收藏接口
- Agent 话术演练前端展示所需接口

### 6.5 销售专属接口权限

以下接口允许 `sales`，并按需要允许 `admin` 后台查看或管理：

- `GET /sales/dashboard`
- `GET /sales/methodologies`
- `GET /sales/methodologies/{id}`
- `POST /sales/audio-files`
- `GET /admin/sales/audio-files`

权限要求：

- `sales` 可查看销售看板和销售方法论。
- `sales` 可上传自己的销售语音文件。
- `admin` 可后台查看全部销售语音文件。
- `student` 不可访问销售看板、销售方法论和销售语音文件相关接口。

## 7. 数据模型调整任务

### 7.1 用户角色字段

复用现有 `users.role` 字段，统一角色值为 `admin`、`sales`、`student`。

需要新增数据迁移：

- 历史角色值迁移。
- 用户管理角色选项更新。
- 登录返回用户信息中的角色值统一。

### 7.2 销售语音文件表

建议新增销售语音文件表，用于保存销售上传的个人语音文件。

建议字段：

- `id`
- `user_id`
- `file_url`
- `filename`
- `duration`
- `file_size`
- `transcript`
- `summary`
- `methodology_id`
- `status`
- `created_at`
- `updated_at`

### 7.3 销售方法论表

建议新增销售方法论表，用于保存销售方法论沉淀内容。

建议字段：

- `id`
- `title`
- `content`
- `source`
- `source_audio_file_id`
- `tags`
- `status`
- `created_by`
- `created_at`
- `updated_at`

销售方法论对所有销售角色可见。

## 8. 前端调整任务

### 8.1 管理端

- 登录后校验用户角色必须为 `admin`。
- 非 `admin` 访问管理端时跳转登录或无权限页面。
- 用户管理角色选项调整为管理员、销售、学员。
- 增加销售语音文件后台查看页面。
- 增加销售方法论后台管理或查看页面。

### 8.2 培训端

- 登录后允许 `sales`、`student` 使用培训端。
- 路由增加角色访问控制。
- 菜单根据角色动态展示。
- 销售显示销售看板、销售方法论入口。
- 学员不显示销售看板、销售方法论入口。
- 实战演练页面最上方增加 Agent 话术演练入口。

## 9. 验证任务

### 9.1 权限验证

- `admin` 可登录管理端。
- `sales` 不能登录管理端。
- `student` 不能登录管理端。
- `sales` 可登录培训端。
- `student` 可登录培训端。
- `sales` 可访问销售看板和销售方法论。
- `student` 不能访问销售看板和销售方法论。
- `sales` 可上传个人销售语音文件。
- `admin` 可后台查看全部销售语音文件。
- `student` 不能上传或查看销售语音文件。

### 9.2 Agent 入口验证

- 销售进入培训端“实战演练”时，页面最上方展示 Agent 话术演练入口。
- 学员进入培训端“实战演练”时，页面最上方展示 Agent 话术演练入口。
- 管理端不展示 Agent 演练记录查看入口。

### 9.3 构建与测试

- 后端权限相关测试。
- 管理端 `npm run build`。
- 培训端 `npm run build`。

## 10. 实施优先级

建议按以下顺序实施：

1. 统一角色枚举与登录返回角色值。
2. 补管理端 `admin` 访问限制。
3. 补培训端 `sales` / `student` 路由和菜单权限。
4. 补后端接口角色拦截。
5. 新增销售看板与销售方法论入口。
6. 新增销售语音文件上传与管理员后台查看。
7. 在实战演练页面最上方增加 Agent 话术演练入口。
8. 后续再完善 Agent 演练记录、评分、复盘与统计闭环。
